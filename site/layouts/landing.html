Meta AI models

One Muse model per feature

Muse Spark enhances and translates, Muse Voice Transcribe dictates, Muse Image illustrates, and Muse SAM keeps uploads safe — one key each, in .env.

 Speech dictation

Features

A single binary runs the whole CMS. Configure content types and fields in config.toml, extend with WebAssembly, and drive it from the terminal. See the full list →

🚀

One binary, no Docker

A static Go binary plus embedded SQLite. No runtime, no container, no node_modules in production.

 🧩

Modular & lean

Eighteen built-in modules with a declared graph — disable what you don't need and the binary stays one lean whole.

 🔌

Headless mode

Flip [headless] enabled = true to serve only the admin panel and REST API — a pure headless CMS.

 🗃️

Two-layer configuration

config.toml holds your content schema; .env holds deployment state. Only JWT_SECRET is required.

 📝

Custom post types & fields

Define post types and fields in config.toml. The admin form, storage, and queries all read from it.

 📦

Importers & Exporters

Migrate from WordPress (WXR) or Hugo — posts, custom fields, media, authors — via async jobs. Export everything as a Hugo-compatible archive and HTML static files.

 🪄

WebAssembly plugins

Drop a .wasm into plugins/ to hook before_save, after_create, after_publish.

 🖼️

Media & WebP

A media library with automatic WebP conversion, configurable thumbnail variants, and dedup.

 🤖

AI built in

Generate images, enhance & translate text, dictate content with your voice, and author on-brand HTML/CSS from a prompt — reusing your theme's design tokens. Bring your own key.

 🌍

i18n by default

Multilingual content with translation groups and hreflang in the sitemap.

 ⚡

SSR, SSG & AMP

Server-rendered and SEO-friendly. Generate a static site with AMP variants via the admin or lesstruct-cli ssg.

 🔗

REST API, CLI & MCP

A versioned /api/v1 with API keys, plus lesstruct-cli for agents and terminals and lesstruct-mcp for MCP-native agents.

 🔐

Roles & security

Cookie sessions with mandatory email MFA, email-or-username sign-in, failed-login lockout, Argon2id, rate limits, and security headers.

 🎛️

Custom roles

Add custom roles or override the built-ins with [[role]] entries in config.toml — per-post-type manage, publish, media, and comment capabilities.

 🛡️

Safe by default

HTML sanitized on write and read, a configurable CSP, and safe-link policies — secure without a security degree.

Model Features
Muse Wonder Extend Lesstruct further with the Lesstruct Module Development skill — optimized for Muse Code and Muse Wonder.
Muse Spark Enhance your writing and translate content into any language you’ve defined in config.toml.

One server, one CLI

One product, one companion tool. SQLite is built in by default; PostgreSQL and MySQL are a configuration away. The API and CLI in the docs →

lesstruct server

The whole CMS as one static binary: admin panel, REST API, and the rendered content site. SQLite by default; PostgreSQL and MySQL via DB_DRIVER.

lesstruct-cli cli

The companion command line for AI agents: content, media, and export operations straight from the terminal.

lesstruct-mcp mcp

The MCP server for AI agents: the same API as 44 tools over stdio or, with [mcp] enabled, the network.
